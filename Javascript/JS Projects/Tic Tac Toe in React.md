
#### Setting up the project
`npm create vite@latest`
Select React and JS.
Cd into your project folder, and `npm i` to install all modules.
`npm run dev`  to run your project

To disable eslint, find `eslint.config.js`, and add `**` to ignore project wide
`ignorePatterns: ['dist', '**']`

first one ignores `dist` directory, second one ignores everything
