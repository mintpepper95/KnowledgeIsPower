
For dijkstra we don't need to track the current path, we just need to know the best score we have at a particular cell.

We can use `None` to represent we haven't explored something to avoid going back and forth, as in this question, the cost of going back and forth maybe 0.

```python
import heapq

  
class Solution(object):

    def findSafeWalk(self, grid, health):
        """
        :type grid: List[List[int]]
        :type health: int
        :rtype: bool
        """

        # we want to make sure we have the maximum health,
        # note with Dijkstra, we can set all nodes to an 'unexplored' status
        # None means not explored yet
        best_health = [[None] * len(grid[0]) for i in range(len(grid))]

  
        # calc initial cost, depends on cell value
        best_health[0][0] = -1 * (health - grid[0][0])

        # turn into a max heap
        # note python only support min heap so turn to max heap by make cost negative
        queue = [(best_health[0][0], 0, 0)]
        heapq.heapify(queue)

  

        while queue:
            # pop the largest remaining health first to process
            health, x, y = heapq.heappop(queue)

            deltas = [(-1, 0), (1, 0), (0, -1), (0, 1)]
            for dx, dy in deltas:
                new_x = x + dx
                new_y = y + dy

  
                # if valid
                if 0 <= new_x < len(grid) and 0 <= new_y < len(grid[0]):
                
                    # we can only calc new health given new cell is valid
                    # we use '+' due to negative costs
                    new_health = health + grid[new_x][new_y]

  

                    # if cell not explored yet or we found a better path, only then keep exploring
                    # we use '<' instead of '>' due to negative costs
                    if best_health[new_x][new_y] is None or new_health < best_health[new_x][new_y]:
                        # update new_health
                        best_health[new_x][new_y] = new_health

                        heapq.heappush(queue, (new_health, new_x, new_y))

  

        # if not reacheable or not enough health

        # best_health stores negative numbers,

        # note this health can turn positive,

        # meaning cost to arrive at end is more than our life

        end = best_health[-1][-1]

        if end is None or -end < 1:

            return False

        return True
```
